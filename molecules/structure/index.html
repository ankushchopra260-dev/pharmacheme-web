Molecule Structure Tool

Draw a structure (click to place atoms, drag to draw bonds, ring and functional-group templates) and get molecular formula, weight, atom/bond counts, and SMILES both ways.

What's Reliable Here

Formula, molecular weight, valence/implicit-hydrogen handling, and SMILES parsing and generation are all computed by OpenChemLib, not a hand-built parser — this covers common organic structures with standard valences (C, N, O, S, P, F, Cl, Br, I) plus the NO₂ group's formal charges.

Known Limitations

This tool does not currently model expanded sulfur/phosphorus valence states, stereochemistry, or fusing a ring template onto an existing atom. InChI generation and a 3D viewer aren't implemented — both would require an additional chemistry library dependency that isn't wired into this build yet, rather than being silently faked.
