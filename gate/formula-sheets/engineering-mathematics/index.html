Engineering Mathematics: GATE CH formula sheet

Thirteen marks are guaranteed from this section in every CH paper, and the questions are usually short. New for GATE 2027: basic AI/ML (linear regression and PCA). Weight in the paper: 13 marks (fixed).

Linear algebra

Eigenvalues
det(A − λI) = 0Sum of eigenvalues = trace; product = determinant
Inverse of 2 × 2
[[a, b], [c, d]]⁻¹ = (1/(ad − bc)) [[d, −b], [−c, a]]
Rank and solutions
rank(A) = rank([A|b]) = n → unique; < n → infinite; rank(A) < rank([A|b]) → none

Calculus

L'Hôpital
lim f/g = lim f′/g′ for 0/0 or ∞/∞
Taylor series
f(x) = f(a) + f′(a)(x − a) + f″(a)(x − a)²/2! + …
Maxima and minima (2 variables)
r = fxx, s = fxy, t = fyy; rt − s² > 0 and r < 0 → maximumrt − s² < 0 → saddle point
Gradient, divergence, curl
∇f = (fx, fy, fz); ∇·F; ∇×FDirectional derivative = ∇f · û
Gauss divergence theorem
∯ F·n dS = ∭ ∇·F dVStokes: ∮ F·dr = ∬ (∇×F)·n dS

Differential equations

First-order linear
y′ + P(x)y = Q(x); integrating factor e∫P dx
Constant coefficients
Roots m1, m2 real: Aem₁x + Bem₂x; repeated: (A + Bx)emx; α ± iβ: eαx(A cos βx + B sin βx)
Cauchy–Euler
x²y″ + axy′ + by = 0: try y = xm
Laplace transforms
L{1} = 1/s; L{eat} = 1/(s − a); L{tn} = n!/sn+1; L{sin at} = a/(s² + a²); L{f′} = sF(s) − f(0)Final value: limt→∞ f = lims→0 sF(s)

Probability and statistics

Binomial
P(k) = C(n, k) pk(1 − p)n−k; mean np, variance np(1 − p)
Poisson
P(k) = e−λλk/k!; mean = variance = λ
Normal
z = (x − μ)/σ; P(|z| < 1) ≈ 0.683, < 2 ≈ 0.954, < 3 ≈ 0.997
Conditional and Bayes
P(A|B) = P(A ∩ B)/P(B); P(A|B) = P(B|A)P(A)/P(B)

AI/ML basics (new)

Least-squares line
b = Σ(x − x̄)(y − ȳ)/Σ(x − x̄)²; a = ȳ − b x̄With an intercept, residuals sum to zero and the line passes through (x̄, ȳ)
R²
R² = 1 − SSres/SStot
PCA
Principal components = eigenvectors of the covariance matrix; variance explained ∝ eigenvaluePC1 is the direction of maximum variance; components are orthogonal

Numerical methods

Newton–Raphson
xn+1 = xn − f(xn)/f′(xn)Quadratic convergence near the root
Trapezoidal rule
∫ ≈ (h/2)[f0 + 2(f1 + … + fn−1) + fn]Error O(h²)
Simpson's 1/3
∫ ≈ (h/3)[f0 + 4(odd) + 2(even) + fn], n evenExact for cubics; error O(h⁴)
Euler method
yn+1 = yn + h f(xn, yn)RK4 is fourth order
Common traps
  • Mixing up Laplace sign conventions: L{e−2t} = 1/(s + 2).
  • Simpson's 1/3 rule needs an even number of intervals.
  • For a 3 × 3 matrix, check the product of eigenvalues against the determinant before choosing an option.
