How this mock test works

The mock follows the GATE Chemical Engineering (CH) pattern: 65 questions for 100 marks in 3 hours. The first 10 questions are General Aptitude (5 one-mark and 5 two-mark, 15 marks). The other 55 are Chemical Engineering, worth 85 marks, of which 13 marks come from Engineering Mathematics. One-mark questions come before two-mark questions in each part, as in the real paper.

Question types and marking

  • MCQ: one correct option out of four. A wrong answer costs 1/3 of the question's marks.
  • MSQ: one or more options are correct. You must pick all the correct ones and nothing else. No negative marking and no partial credit.
  • NAT: type a number. Any value inside the accepted range scores. No negative marking.

Using the screen like the real exam

  • The question palette shows which questions you have answered, not answered, not visited or marked for review.
  • "Save and next" records your answer. "Mark for review and next" flags it so you can come back. A marked question that has an answer is still counted.
  • The on-screen calculator has the same layout and keys as the virtual calculator in the GATE exam, including Deg/Rad, memory, Exp, logᵧx and ʸ√x. Practise with it, because GATE does not allow your own calculator.
  • The timer keeps running if you reload the page, and the test submits itself when time runs out.

After you submit

You get your raw score out of 100, marks lost to negative marking, and a section-wise table. Every question can be reviewed with the correct answer and a worked solution. Each new attempt draws a fresh set from our bank of 105 questions, so later attempts repeat fewer questions.

Weak in a section? Revise its formula sheet, then work through the practice questions for that section.

This is a practice mock written for PharmaChemE, not an official GATE paper. The real GATE score is normalised; this mock shows raw marks. For official information, see the GATE 2027 site.
